## 一、项目背景与问题

双黑洞（BBH）初始数据求解的核心是**哈密顿约束方程**——一个以共形因子 ψ 为未知量的
椭圆型方程：

```
Δψ + (1/8) ψ⁻⁷ K̄_ij K̄^ij = 0 ,   ψ = ψ_sing + u
```

传统做法（TwoPunctures 等谱代码）每换一组物理参数（质量比、动量、自旋）都要**重新
求解一次**。A2 的目标：训练**单个**神经网络，输入 (x, 参数 q) 一次前向即给出任意
q ∈ [0.5, 2.0]（质量比，m1=0.5 固定）的解——把"解单个算例"升级为"参数空间的
连续解算子"。这是本项目三阶段（A1 单配置复现 → **A2 参数化初探** → A3 八维全参数）
中的第二阶段，也是 A3 的方法基础。

## 二、方法

- **引导式硬约束 ansatz**（对论文 Eq.5 的参数化推广）：

  ```
  u_θ(x; q) = κ(q) · u_g(x; q) · [ 1 + c · W(x; q) · tanh( h_θ(x, q) ) ]
  ```

  u_g：LZ 解析引导解（动量项）；κ(q)：散度定理 + 200k QMC 预计算**查表**；
  W：引导解窗函数；h_θ：FiLM 条件 MLP（4×128 + 正弦位置编码，约 14.3 万参数），
  参数 q 经归一化与正弦编码注入。
- **训练**：参考监督（base q=1 有 TwoPunctures 参考解，L_ref = L2RE²，权重课程衰减）
  + PDE/Robin 残差正则（全部 q），每步随机抽 1 个配置。
- 训练 15000 步约 60 分钟（单块 RTX 4070 Ti SUPER）。

## 三、创新点

1. **参数化引导 ansatz**：解析先验（引导解 + κ 标定）作为硬约束基底，边界条件与
   奇点结构由架构保证，网络只学乘性残差修正——把物理结构知识放进架构而非让网络
   从零拟合。
2. **单网络覆盖参数连续统**：q∈[0.5,2] 一个模型，未见过的 q **零样本**直接预测。
3. **方法学发现**（对后续所有参数化 PINN 有效）：纯 PDE 残差训练对参数化 PINN
   **无效**——残差对 κ 全局尺度误差不敏感（L2RE≈0.09 时残差已达 ~1e-10），
   必须叠加参考监督或准确定标 κ。
4. **每步随机单配置**的参数空间 mini-batch：比每步遍历全部配置快 6 倍、精度相当。
5. **κ 查表**：避免 QMC 积分噪声（200k 点运行间波动 2~3%）直接进入训练目标。

## 五、不足（诚实评估）

1. **参数维度单一**：仅质量比 q；位置/动量/自旋固定（x±=±3，P±=(0,∓0.2,0)，S=0）。
2. **逐 q 误差此前无参考解量化**（已部分解决，2026-08-30）：自研谱方法参考解求解器
   （不依赖 GSL，与 A3 同一套件，base 对 TwoPunctures L2RE=6.35e-5）已为全部 10 个
   剖面配置生成 L=48 参考解（`paper/tools/refs_a2/`），剖面图三线对比已实现；
   尚未做：逐 q L2RE 数值表与留出法误差评估。
3. **近场（针尖）误差未量化**：A3 的谱参考解复核表明 LZ 引导解在轻质量+高动量
   奇点近场可偏离真值 1.5~2×，而乘性修正头受 1+c·W 幅值上限约束——该结构性问题
   A2 同样存在（A2 的窗口函数恰好处在有利范围，故能学，但上限行为未检验）。
4. **远场退化**：u_g 远场形状偏差导致的 r>10 误差（见上表）。
5. **外推不对称**（泛化测试结论，脚本已归档、报告保留）：q>2 外推优于训练
   （残差 0.2~0.3×），q<0.5 退化（~6.6×）——轻奇点动量项 ∝(2P/m₂)² 在 m₂→0 时
   剧增，引导解形态剧变；轻奇点配置应纳入训练集。
6. **κ 仍需预计算**（非端到端）。

## 六、未来方向

1. **A3 八维参数化**（已启动）：质量+位置+动量+自旋全参数空间，v5 版 base L2RE
   已达 **0.52%**（多配置谱参考监督 + 针尖聚焦配点 + sigmoid 幅值）；遗留改进见
   根目录 `todo.md`。
2. **谱参考解套件接入 A2**（已完成接入）：逐 q 剖面对比已实现；下一步做逐 q L2RE
   数值化、留出法验证、近场（针尖）误差定量。
3. **ansatz 升级**：逐配置自适应窗函数尺度、逐点幅值 c(x)、soft-L∞ 大残差加权
   （优先级排序见 `todo.md`）。
4. **尺度不变性约化**（v6 方向）：(x,m,P,S)→(λx,λm,λP,λ²S) 可约掉一个纯尺度维度，
   等效加密参数覆盖。
5. **端到端 κ**：把 κ 的散度定积分入损失，消除预计算环节。
