## 1. 研究背景与问题

### 1.1 为什么需要数值相对论（NR）初始数据

- 引力波天文学（GW150914 以来）需要**源建模**：为探测与参数估计提供高精度波形模板。
- 双黑洞并合（CBC）的波形模板来自**数值相对论（NR）**——数值求解 Einstein 方程。
- NR 把 Einstein 方程改写为 **3+1 Cauchy 初值问题**：先构造**满足约束方程的初始数据**，再时间演化。

### 1.2 初始数据问题 = 求解哈密顿约束

在**共形平直**（γ_ij = ψ⁴ f_ij）与**极值切片**（K=0）假设下，哈密顿约束化为 **Lichnerowicz 方程**：

$$\Delta \psi + \frac{1}{8}\psi^{-7}\bar{K}_{ij}\bar{K}^{ij} = 0 \tag{1}$$

其中 $\bar{K}_{ij}$ 由 **Bowen-York 解**（动量约束的解析解）给出：

$$\bar{K}_{ij} = \sum_n \left[ \frac{3}{2r_n^3}\left(x_n^i P_n^j + x_n^j P_n^i - \left(\delta^{ij} - \frac{x_n^i x_n^j}{r_n^2}\right) P_n^k x_n^k\right) + \frac{3}{r_n^5}\left(\epsilon^{ikl} S_k^n x_n^l x_n^j + \epsilon^{jkl} S_k^n x_n^l x_n^i\right) \right] \tag{2}$$

- $r_n = \|\vec{x} - \vec{x}_n\|$，$n=1,2$ 标记两个奇点（puncture）；
- $P_n^i$、$S_n^i$ 分别为黑洞的**线动量与自旋**。

### 1.3 奇点分解：把发散部分解析化

共形因子在奇点处 ~1/r 发散，直接数值求解困难。做 **puncture 分解**（Brandt-Brügmann）：

$$\psi = 1 + \sum_n \frac{m_n}{2 r_n} + u \tag{3}$$

其中 $u$ 是**全空间有界、光滑**的修正项（$u \to 0$ 当 $r \to \infty$）。代入 (1) 得 $u$ 满足的方程：

$$\Delta u + \frac{1}{8}\psi^{-7}\bar{K}_{ij}\bar{K}^{ij} = 0 \tag{4}$$

> **本论文/本项目求解的对象就是 (4)**：一个高度非线性的椭圆型 PDE，定义在 $\mathbb{R}^3$ 上。

### 1.4 为什么传统 PINN 难解，论文的动机

- (4) 高度非线性（$\psi^{-7}$ 项），且解在奇点附近变化剧烈（~1/r 结构虽被解析剥离，但 $u$ 仍有强场区特征）。
- 直接让网络学 $u$ 很难收敛到全局正确解（论文消融显示：无引导时 L2RE ≈ 0.24，差一个数量级）。
- 论文的**核心贡献**：引入一套技巧组合，使 PINN 首次成功求解 BBH 哈密顿约束。

## 2. 论文核心方法（模型架构）

### 2.1 引导式硬约束 ansatz（Eq.5）—— 论文的灵魂

网络不直接输出 $u$，而是输出一个**有界修正比例场** $h_\theta(x)$，再通过解析结构强制组装：

$$\boxed{\,u_\theta(x) = \kappa\, u_g(x)\left[1 + c\, W(x)\, \tanh\!\big(h_\theta(x)\big)\right]\,} \tag{5}$$

各要素：

| 符号 | 含义 | 作用 |
|---|---|---|
| $u_g$ | **解析引导解**（Lousto-Zlochower 2008） | 提供解的全局结构、量级、符号 |
| $\kappa$ | 全局尺度因子 | 两阶段训练**阶段一**由散度定理确定 |
| $c$ | 修正幅度超参数（base 取 0.2） | 控制网络修正相对引导解的强度 |
| $W(x)$ | **窗函数**（Eq.7） | 控制修正的空间作用范围 |
| $\tanh(h_\theta)$ | 网络输出（有界于 (-1,1)） | 唯一可学习的自由度 |

**设计精髓**：
- $\tanh$ 把修正压到 $(-1,1)$，修正项**永不爆炸**；
- 乘法形式保证修正与局部解值**成比例**（强场区修正大、弱场区修正小）；
- 解的符号、量级、远场衰减被解析结构**硬性保证**——网络只学"偏差"，训练极稳。

### 2.2 引导解 u_g（Eq.6，Lousto-Zlochower 2008）

$$u_g = u_P + u_J + u_c \tag{6}$$

- $u_P$：**动量项**（boosted puncture 的解析近似，含勒让德多项式 $P_2$ 展开）；
- $u_J$：**自旋项**；
- $u_c$：**动量×自旋交叉项**。

每个奇点独立计算后线性叠加（多奇点叠加原理）。本项目在 `physics.py` 中按 LZ2008 原文公式逐项实现。

### 2.3 窗函数 W（Eq.7）

$$W(x) = \frac{u_g(x) - u_{\min}}{u_{\max} - u_{\min}} \tag{7}$$

- 把引导解线性映射到 $[0,1]$；
- $u_g$ 大（奇点附近强场区）→ $W \approx 1$ → 网络有**完全修正权**；
- $u_g$ 小（远场）→ $W \to 0$ → 修正被抑制，解由 $\kappa u_g$ 决定。

> **论文的消融证明窗函数形式重要**：换成一般光滑窗（每个奇点一个 $\tanh$ 过渡窗，Eq.21）后 L2RE 从 0.017 恶化到 0.087。

### 2.4 边界条件：Robin 型（Eq.8）

计算域取球 $\Omega$（$r \le R_{\max}=30$），边界上施加 **Robin 边界条件**（模拟 $u \sim 1/r$ 的远场衰减）：

$$\vec{n}\cdot\nabla u + \frac{1}{r}\frac{\partial r}{\partial n} u = 0 \quad \text{at } \partial\Omega \tag{8}$$

球面上 $\partial r/\partial n = 1$，等价于 $\partial u/\partial r + u/r = 0$。

### 2.5 网络结构（§II.B.4）

- **3 个隐藏层 × 64 神经元**，全连接 MLP；
- 激活函数 **SiLU**：$\mathrm{SiLU}(x) = x/(1+e^{-x})$；
- 输入 3 维坐标 $\vec{x}$，输出 1 维修正场 $h_\theta$；
- 优化器 **Adam**，学习率 $3\times10^{-4}$，训练 **5000 步**。

### 2.6 两阶段训练（阶段一：κ 的解析定标）

**阶段一**（Eq.9-10）：对 (4) 应用**散度定理**，代入 $u = \kappa u_g$（即 $h_\theta=0$）：

$$-\kappa \oint_{\partial\Omega} \nabla u_g \cdot \vec{n}\, dS = \frac{1}{8}\int_\Omega \bar{K}_{ij}\bar{K}^{ij}\left(\psi_{\text{sing}} + \kappa u_g\right)^{-7} dV \tag{10}$$

- 用 **Sobol 序列拟蒙特卡洛（QMC）** 计算积分：体积 $5\times10^6$ 点 + 边界 $5\times10^4$ 点；
- 对 $\kappa$ 解这个**一元标量方程**（二分法/brentq）；
- 论文明确说明：κ 只需"够用"，不必精确（它只调整 $h_\theta$ 解的结构）。

**阶段二**：固定 κ，训练网络 $h_\theta$，最小化复合损失（见 §3）。

## 3. 优化方法（损失函数与训练策略）

### 3.1 复合损失（Eq.11-15）

$$L = L_{\text{PDE}} + L_{\text{BC}} \tag{11}$$

$$L_{\text{PDE}} = w_2\, L_2 + w_\infty\, \text{soft-}L_\infty \tag{12}$$

**L2 损失**（PDE 残差均方误差）：

$$L_2 = \frac{1}{N_\Omega}\sum_{i=1}^{N_\Omega} R_i^2 \tag{13}$$

**soft-L∞ 损失**（log-sum-exp 光滑化的 L∞，Eq.14）：

$$\text{soft-}L_\infty = \frac{1}{\beta}\ln\!\left(\sum_{i=1}^{N_\Omega} e^{\beta |R_i|}\right) - \frac{1}{\beta}\ln N_\Omega \tag{14}$$

- $\beta$ 控制逼近 L∞ 的尖锐度（$\beta$ 越大越接近最大残差）；
- 光滑形式既约束大残差，又避免 L∞ 的不可微。

**边界损失**（Robin 边界残差均方误差）：

$$L_{\text{BC}} = w_{\text{rob}} \cdot \frac{1}{N_{\partial\Omega}}\sum_{i=1}^{N_{\partial\Omega}} R_{B,i}^2 \tag{15}$$

**采样**：训练前均匀随机选取 $N_\Omega = 20000$ 内部点 + $N_{\partial\Omega} = 8000$ 边界点。

### 3.2 EMA 损失平衡（Eq.16-17）—— 论文的第二个关键技巧

三个损失分量量级可能差几个数量级，直接相加会让大项主导优化。用**指数滑动平均（EMA）**动态归一化：

$$\bar{L}_k(t_n) = \alpha\, \bar{L}_k(t_{n-1}) + (1-\alpha)\, L_k(t_n) \tag{16}$$

$$\tilde{L}_k(t_n) = \frac{L_k(t_n)}{\bar{L}_k(t_n)} \tag{17}$$

- 每个损失项除以自己的 EMA，被**归一化到 O(1)**；
- 任何一项都不会独大，多损失训练稳定有效；
- $\alpha = 0.9$（论文未给具体值，本项目取常见值）。

### 3.3 base 算例的超参数（§II.B.4）

| 参数 | 值 | 说明 |
|---|---|---|
| 物理参数 | $m_\pm=0.5$，$x=\pm3$，$P_{+y}=-P_{-y}=0.2$ | 等质量、无自旋、带轨道角动量 |
| $c$ | 0.2 | 修正幅度 |
| $w_2, w_\infty, w_{\text{rob}}$ | 1.0, 0, 1.0 | base 算例**不用 soft-L∞** |
| $\beta$ | 2.5 | （base 中 $w_\infty=0$ 未启用） |
| lr / 步数 | $3\times10^{-4}$ / 5000 | Adam |
| $R_{\max}$ | 30 | 球域半径 |

### 3.4 评估指标：L2RE（Eq.18）

在 **TwoPunctures 谱网格节点**上对比 PINN 解与参考解：

$$\text{L2RE} = \sqrt{\frac{\sum_{i=1}^{N_{\text{grid}}} |u_{\text{PINN}}(x_i) - u_{\text{TP}}(x_i)|^2}{\sum_{i=1}^{N_{\text{grid}}} |u_{\text{TP}}(x_i)|^2}} \tag{18}$$

- TP = TwoPunctures（Ansorg-Brügmann-Tichy 2004 谱方法求解器）参考解；
- 每个配置独立训练 **5 次**（不同随机种子），报告均值 ± 标准差。

## 4. 论文结果与消融

### 4.1 base 算例主结果（Table I 第一行）

$$\text{L2RE} = 0.0172 \pm 0.0040 \quad (\text{约 } 1\% \text{ 精度})$$

- L2 损失单调下降（Fig.2a）→ 优化稳定；
- L2RE 前几百步快速下降，随后缓慢收敛到 ~10⁻² 平台（Fig.2b）；
- x 轴剖面与参考解几乎完全重合，含奇点邻域（Fig.2c）；
- z=0 赤道面整体复现，主要偏差集中在奇点附近强场区（Fig.2d）。

- 单配置 5000 步在单张 **NVIDIA L40** 上约 **30 分钟**；
- 约为 TwoPunctures 的 **25 倍**——单配置求解 PINN 更慢；
- 论文强调：**主要目的是证明 PINN 能解哈密顿约束**，效率提升留给参数化求解器（未来工作）。

> 本节是**本项目相对论文的增量**。核心成果：**base 算例 L2RE 从 0.133 修复到 0.0067，稳定优于论文的 0.017**。完整过程见 `paper/A1_reproduction_report.md`。

### 5.1 复现环境

| 项 | 值 |
|---|---|

| torch | 2.13.0+cu130（CUDA 13.0） |
| GPU | NVIDIA RTX 4070 Ti SUPER 16 GB |

### 5.2 创新点 1：定位并修复了"峰值优化"导致的精度退化（根因分析）

**现象**：项目初始配置（`base_full`）L2RE = 0.133，比论文差一个数量级。

**诊断方法**（7 个诊断脚本，`paper/analysis/a1_diag_*.py`）：
1. **分区误差定位**：按到最近奇点距离分桶，发现误差**不在奇点邻域而在 bulk**（r∈(2,10) 区 L2RE=0.134 主导）；
2. **尺度偏差检测**：沿穿洞 x 轴，网络输出 ≈ **0.84·u_ref**（系统性欠 scale ~16%），线性拟合 `u_pinn = 0.839·u_ref + 2e-4`——纯尺度偏差；
3. **对照实验**：静态满修正函数 `κ·u_g·(1+c·W)`（tanh=1）在同一参考上 L2RE = 0.017（=论文值）→ 问题不在 ansatz 结构；
4. **κ 偏差量化**：散度定理 κ=0.637 vs 最优尺度 κ=0.723（差 12%），且 `κ_opt·u_g` 的 L2RE=0.026 → **u_g 形状很好，只差尺度**；
5. **窗函数可达性分析**：所需修正比 `u_ref/(κ·u_g)` 为 1.02~1.21（几乎均匀 +9%），但可达带 `1±c·W` 在 bulk 仅 ±0.008 → **90% 的点落在可达带外**，bulk 尺度只能由 κ 决定。

**根因**：项目自加的"峰值优化"（**峰值加权 w∝1/r** + **自适应采样** 50% 点集中 r<2）把训练监督集中到奇点邻域，bulk 被欠加权 ~1000 倍 → 网络停在 κ·u_g 尺度。

**修复**：关闭二者，恢复论文的**均匀采样 + 均匀 L2 损失**，并把 κ 的 QMC 点数对齐论文（5e6）。

**对照实验证实**（GPU 5000 步）：

| 实验 | 峰值加权 | 自适应采样 | L2RE（全参考） |
|---|---|---|---|
| base_full（旧默认） | 开 | 开 | 0.133 |
| **E1（纯论文配置）** | **关** | **关** | **0.0089** ✓ |
| E2 | 关 | 开 | 0.087 |

> **结论**：论文的"均匀采样 + 均匀损失"是精度关键；项目早期为"优化峰值"而加的技巧反而有害。这是一个**反直觉的、有价值的复现发现**。

## 6. 局限与后续方向

### 6.1 论文自身的局限（§V 承认）

1. **超参数依赖人工调节**：c、w∞、β、lr 需按算例手动挑选（论文只做了部分组合测试，未做全网格搜索）；
2. **单配置求解慢**：比 TwoPunctures 慢 ~25 倍，效率上无优势；
3. **自旋算例精度有限**：L2RE ~0.08-0.09，明显差于非自旋；
4. **未来工作**：参数化 PINN 初始数据求解器（一个网络覆盖参数空间）。

### 6.2 本项目复现中发现的局限（A1 报告 §7）

1. **远场残余尺度偏差（r>10，~2.5%）**：源于 u_g 远场形状与真实解差 12%，而 κ 无法由散度定理修正（散度定理只约束整体通量，不约束逐点形状）。后续可试：增大 c_guide、更大网络、或在损失中加入"散度定理对完整解 u_θ 成立"的约束。
2. **近奇点残余（r<1，~2%）**：均匀采样在峰值区点数偏少。若需进一步压峰值误差，可试**温和**加权（权重上限 10×，而非原峰值加权的 ~1400×）。
3. **其余三算例未跑通**：spin_eq / uneq_nospin / uneq_spin 待用同一修复后配置跑通，产出完整 Table II 复现表。
4. **评估口径差异**：全自适应参考（47.7M 点）比论文谱网格更严格，L2RE 数值不可直接与论文逐位对比（量级一致即可）。

### 6.3 后续研究方向（详见 `research_directions.md`）

- **A2（最优先）**：参数化 PINN / 初始数据神经算子——输入 `(x; m1, m2, P±, S±)` 直接输出 u，一个网络覆盖参数空间（论文 §V 明确指出的未来方向）；
- **C1**：把"引导解 ansatz + 两阶段定标 + EMA 平衡"迁移到 Teukolsky/QNM、静态时空等；
- **B1/B2**：激活 `BBH/` 的 17.5 GB 演化数据（时空 INR、旋近可观测预测）；
- **C2**：初始数据 → 演化 → 可观测的整链路神经代理。
