## 1. 背景诊断(为什么旧 A2 在大 q 上会差)

1. **旧训练区间浪费**:旧 A2 训练 q∈[0.5,2](q=m2/m1,m1=0.5 固定)。q 与 1/q 的
   构型互为镜像(x→−x, P→−P),物理等价,同时训练是浪费;q>2 的真实大质量比从未覆盖。
2. **全局窗口归一化压制轻配置**:旧 ansatz 的 w=(u_g−u_min)/(u_max−u_min) 用全体
   配置的全局 min/max。u_g 峰值 ∝ m²,配置间相差 (m2max/m2min)²;旧区间 16 倍、
   新区间(0.5→5)100 倍。轻配置的修正项被压缩到 ~1%——这与"轻 q 赤道面残差
   差 ~50×"的诊断一致。**新方案改为逐配置归一化**。
3. **参数编码不适配大范围**:旧参数正弦编码对 m2 原值编码,频率 e^7≈1096,m2 到 5
   时严重混叠。新方案输入 [log10(q), m2/5]。
4. **残差量级跨配置失衡**:u_g RMS 随 m² 增长,大 q 配置的 PDE 残差天然大。
   新方案逐配置用 sq=√⟨u_g²⟩ 归一化,使各配置贡献可比。

且远场模型反而不如引导(×0.9-1.0)—— 修正项在远场 w→0 无力补偿。

**(b) 远场不是纯幅值问题,但有幅值成分**(a2q_kappa_fit.py,κ* 最小二乘标定):
κ*_all 比 QMC κ 系统性低 0.8~1.5%(随 q 单调增);用 κ* 重标定后引导解远场
仍剩 1.9~2.4e-2 —— 引导解远场还缺与 q 相关的多极矩形状分量。

**(c) ansatz 表达力充足,瓶颈在多损失优化干扰**(决定性小实验 a2q_ft_test.py):
从 champion 权重出发,剥离 PDE/边界/正则,纯 refsub 回归(15 配置全监督、
全量 10240 点/配置、lr 1e-4):L_ref 从 8.7e-4 **持续下降至 3.8e-4(3000 步,
仍在降)** —— 同一个网络,同样的点,仅去掉 PDE 项,L_ref 即降到 champion
15000 步全程下限(~3.1e-3)的 1/8 以下。**champion 的"平坦 L_ref"是多损失
(PDE 均值 vs 参考回归)梯度干扰所致,不是 ansatz 表示力极限。**

**(d) 汇聚成对策 champion-v2**(待实施):
1. 两阶段训练:先 PDE(已有 champion 权重)→ 再 PDE+全配置 ref 联合微调
   (每步 15 配置 ref 全量,λ_ref 保持下限;而非每步随机 3 配置);
2. κ 重标定:训练与评估前把 κ 替换为 κ*(a2q_data/kappa_star.json);
3. 若联合微调后远场仍不够,再叠加"远场加密 refsub"(球壳 r∈[6,30] 加采)。

### 6.2 核心成果

1. **q=1.0 达 A1 base 水准**:L2RE 5.9e-3 ≈ A1 的 6.7e-3(自研全参考口径)✓
2. **灾难区根因找到并修复**:旧 κ 缓存的 QMC 噪声(±21%,q20 虚高 18%)。
   修正后 + 全配置监督,全域最差 L2RE 从 0.21 → 0.035(6×),q∈[1,10] 均匀 ≤3.5e-2
3. **第二段无人值守再进一步**:champion2(κ* 标定 + 全配置 ref 全量监督)把
   训练配置全域 mean 从 3.15e-2 → **2.40e-2(−24%)**,大 q 端 1.9~2.5e-2。
   距 A1 base(6.7e-3)还差 ~3×,剩余主导项 = 远场引导解形状误差(§5.8)。

### 6.3 方法学发现(对后续 A2/A3 工作最有价值)

1. **κ 缓存 QMC 噪声**:逐配置独立随机种子 + 20 万点 Sobol → κ(q) 非单调
   跳变 ±21%,跳变位置与模型失败区严格重合。V(κ)=∫KK/ψ⁷ 由奇点邻域主导,
   200k 点远不够。修正 = 同种子 200 万点(18 配置仅 3 min)。旧 A2/A3 的 κ
   同样有此隐患(训练区间窄、噪声相对小,故未暴露)。此外 QMC κ 还含
   0.8~1.5% 系统性偏差(κ* 标定可消,a2q_kappa_fit.py)。
2. **ansatz 自由度不是瓶颈**(v1/v2 双重证明):神经算子(v1 逐点特征、
   v2 邻域 patch 真泛函输入)与缩放因子在相同损失下都退化为"常数幅度
   重标定"(ψ 全分位数恒定、几何相关 ≈0)。精度由损失结构与监督定位决定。
3. **全域误差的三层结构**(§5.7-5.8):①κ 幅值/系统偏差(已消);
   ②多损失梯度干扰(PDE 均值淹没参考回归——纯 ref 微调 L_ref 可降 2.4×,
   全配置 ref 全量监督回收 −24%);③远场引导解形状误差(当前主导,
   w 调制的修正项在远场失去杠杆,模型只能贴着引导)。
4. **多配置监督的正确姿势**:每步随机 3 配置 → 参考梯度被 PDE 均值淹没
   (champion L_ref 15000 步平坦);改为每步全 15 配置 ref 全量后立即突破
   (champion2)。A3 八维参数空间应直接采用"全配置 ref 监督"配方。
