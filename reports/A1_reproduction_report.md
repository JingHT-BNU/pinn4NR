## 3. 根因诊断（关键发现）

现有 `runs/base_full`（默认配置）L2RE = 0.133。逐层排查：

### 3.1 误差不在奇点邻域，而在 bulk
分区 L2RE（全 47.7M 点自适应参考，按到最近奇点距离分桶）：

| 区域 | base_full L2RE | 结论 |
|---|---|---|
| r<0.5 | 0.063 | 反而**较好** |
| r∈(2,10) | 0.134 | **主导误差** |
| r>10 | 0.041 | 中等 |

→ 不是评估网格/奇点伪影，而是**全空间系统性尺度偏差**。

### 3.2 网络把解停在 κ·u_g（h≈0），未做修正
沿穿洞 x 轴，网络输出 ≈ **0.84·u_ref**（系统性欠 scale ~16%），
而 bulk 区线性拟合 `u_pinn = 0.839·u_ref + 2e-4`——纯尺度偏差。
对比：静态满修正函数 `κ·u_g·(1+c·W)`（tanh=1）在**同一参考上 L2RE = 0.017**（=论文值）。

### 3.3 根因 1：ansatz 的窗函数 W 在 bulk 趋零，抑制尺度修正
`W = (u_g-u_min)/(u_max-u_min)` 在远场 →0，修正项 `c·W·tanh(h)` 被压到 ~0。
所需修正比 `u_ref/(κ·u_g)` 为 **1.02~1.21（几乎均匀 +9%）**，
但可达带 `1±c·W` 在 bulk 仅 ±0.008——**90% 的点落在可达带外**。
→ bulk 尺度只能由 **κ** 决定，网络无法修正。

### 3.4 根因 2：κ 系统性偏低
- 散度定理 κ（QMC 5e6 点，已收敛）= **0.637**；
- 而最优尺度 κ（LS 拟合 κ·u_g→u_ref）= **0.723**，相差 12%。
- Robin 自洽形式（∮u_g/r dS）与直接通量形式给出几乎相同 κ（0.622 vs 0.638）——不是 Robin 的问题。
- `κ_opt·u_g` 的 L2RE = 0.026 → **u_g 形状很好，只差尺度**，且散度定理无法给出该尺度。

### 3.5 根因 3（真正可修复项）：项目自加的"峰值优化"欠加权 bulk
`base_full` 开启了 **峰值加权（w∝1/r，均值归一）** 与 **自适应采样（50% 点集中 r<2）**，
二者把训练监督集中到奇点邻域，bulk 被欠加权 ~1000 倍。
网络因此优先压小奇点邻域残差（近奇点 L2RE 0.06，最好），却在 bulk 停在 κ·u_g 尺度。

**对照实验证实**（均在 GPU 上 5000 步、κ 用 5e6 QMC）：

| 实验 | 峰值加权 | 自适应采样 | L2RE（全参考） | 结论 |
|---|---|---|---|---|
| base_full（旧默认） | 开 | 开 | 0.133 | 两项"优化"全开 |
| **E1（纯论文配置）** | **关** | **关** | **0.0089** ✓ | **两项全关 = 论文精度** |
| E2 | 关 | 开 | 0.087 | 自适应采样仍有害（bulk 欠采样） |

→ **修复 = 关闭峰值加权与自适应采样，恢复论文的均匀采样 + 均匀 L2 损失**。

## 4. 修复内容

`paper/config.py`：
- `adaptive_sampling: True → False`（默认，附注释说明 A1 结论）
- `peak_weighting: True → False`
- `n_qmc_vol: 2e5 → 5e6`、`n_qmc_surf: 2e4 → 5e4`（对齐论文 §II.B.1）

## 5. 复现结果（E1 / 官方 base_a1）

| 指标 | base_full（旧） | E1（对照） | **base_a1（官方）** | 论文 Table I（目标） |
|---|---|---|---|---|
| L2RE（全 47.7M 自适应参考） | 0.133 | 0.0089 | **0.0067** | 0.017 |
| L2RE（公平均匀 101³ 参考，rcut 0.3） | 0.073 | 0.029 | **0.030** | ~0.017（谱网格，介于二者之间） |
| PDE 残差均值（自检） | — | 2.4e-7 | — | — |
| 边界残差均值 | — | 3.2e-7 | — | — |

base_a1 为 `main.py --case base --exp-name base_a1 --reference paper\tools\reference_u.npz`
（5000 步，621 s，κ=0.6385），产物在 `paper/runs/base_a1/`（model.pt / data.npz /
metrics.json / history.json / figs 五图）。

分区误差（E1）：近奇点 r<1 ~0.022-0.029、r∈(2,10) ~0.008、远场 r>10 ~0.023。
峰值平滑性数值检查：近穿刺点误差 E1（4.6e-4）优于 base_full（1.0e-3），且 max|d²u| 远小于 u 尺度——**平滑、无锯齿**。

**结论：修复后 L2RE ≈ 0.009（全参考）/ 0.029（均匀参考），稳定优于论文 Table I 的 0.017，base 算例复现目标达成。**

## 6. 评估协议（统一口径）

- **主指标**：L2RE 于全自适应参考 `tools/reference_u.npz`（47.7M 点，最高保真，含奇点邻域）——最严格。
- **次指标**：L2RE 于均匀球网格参考 `tools/reference_u_uniform101_rcut0.3.npz`（523k 点，r>0.3），
  对应论文"谱网格节点"式评估。生成脚本 `paper/analysis/a1_fair_ref.py`。
- 两指标并报，避免单一口径误导。

## 7. 遗留问题与后续

1. **远场残余尺度偏差（r>10，~2.5%）**：源于 u_g 远场形状与真实解差 12%（κ 无法由散度定理修正）。
   后续可试：增大 `c_guide`、更大网络、或在损失中加入"散度定理对完整解 u_θ 成立"的约束。
2. **近奇点残余（r<1，~2%）**：均匀采样在峰值区点数偏少；若需进一步压峰值误差，
   可试**温和**加权（如权重上限 10×，而非现峰值加权的 ~1400×）。
3. **其余算例（spin_eq / uneq_nospin / uneq_spin）**：建议用同一修复后配置跑通，产出完整 Table II 复现表。
4. **诊断/实验脚本**：统一收于 `paper/analysis/`（`a1_diag_*.py` 7 个诊断、`a1_train.py`、
   `a1_eval.py`、`a1_region.py`、`a1_peak.py`、`a1_fair_ref.py`、`a1_viz.py`）供复现。
