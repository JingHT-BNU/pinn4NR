# A1 — Reproducing the Paper: Single-Configuration PINN

Companion code for the **paper reproduction** stage of our study on solving
the Hamiltonian constraint of binary black hole initial data with
physics-informed neural networks.

Reference paper: **Solving Hamiltonian Constraint Equation with
Physics-Informed Neural Networks** (arXiv:2607.06002v1).

## What this branch does

Trains a physics-informed neural network for **one BBH configuration at a
time** (four test cases: `base`, `a1`, `b2`, `b4`), implementing every core
technique of the paper:

- **Guided hard-constraint ansatz** (Eq. 5): `u = κ·u_g·(1 + φ_θ)` with the
  analytic Lousto–Zlochower guide solution `u_g` (Eq. 6) built in — boundary
  and asymptotic conditions are satisfied exactly, the network only learns
  the correction `φ_θ = c·w·tanh(h_θ)`;
- **κ energy calibration** (Eqs. 9–10), **window function** (Eq. 7),
  **Robin exterior boundary** (Eq. 8);
- **Composite loss** (Eqs. 11–15) with **EMA loss balancing** (Eqs. 16–17);
- Puncture singularity split `ψ = (1 + Σₖ mₖ/2rₖ)/α + u` (Eq. 3) and
  Bowen–York extrinsic curvature (Eq. 2).

## Results

| Case | L2RE (our full reference) | L2RE (paper Table I metric) |
|------|------|------|
| base | **0.0067** | 0.017 |

`base` matches the paper's accuracy and serves as the quality benchmark for
all later parametric stages. L2RE is evaluated on an 81³ uniform grid over
[-30,30]³, excluding the puncture balls (r < 0.3), against a
spherical-harmonic spectral solution (L=48) cross-validated with the
independent TwoPunctures code.

## Repository layout

```
main.py      # entry point: --smoke / full training / evaluation / figures
model.py     # GuidedPINN: 3×64 SiLU MLP correction field
train.py     # Adam + EMA balancing + singularity regularization
evaluate.py  # L2RE (needs a reference solution) or residual self-check
visualize.py # loss curves / x-axis profiles / equatorial-plane maps
physics.py, config.py, data.py, logutil.py   # shared core
tools/       # spectral reference solver (L=48) + tip-behavior verification
```

## Running

```cmd
:: smoke test (CPU, ~1-3 min, validates the pipeline only)
python main.py --smoke

:: full training for the base case
python main.py --case base --steps 15000
```

Generating the spectral reference solution (needed for L2RE):

```cmd
python tools\spectral_reference.py --params "0.5,0.5,3,-3,0.2,-0.2,0,0" --lmax 48 --out data\ref_base.npz
```

Large data (reference solutions, training outputs) lives in `data/`
(git-ignored) and is regenerated by the commands above.
