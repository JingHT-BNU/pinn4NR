# pinn4NR — Physics-Informed Neural Networks for Binary Black Hole Initial Data

Companion repository for our research on solving the Hamiltonian constraint
(Lichnerowicz equation) of binary black hole (BBH) initial data with
physics-informed neural networks (PINNs). The published paper

**Solving Hamiltonian Constraint Equation with Physics-Informed Neural Networks** (arXiv:2607.06002v1) is used as the *reference method*; our contribution is the parametric extension (A2/A3) presented in the variant branches.

## Overview

The Hamiltonian constraint of Bowen-York puncture data reduces to a nonlinear
elliptic equation for the conformal factor. Following the reference paper, we
embed a closed-form *guide solution* into a hard-constraint ansatz and train a
small MLP to learn only the residual correction — then extend this single-case
solver to **parametric** models: one network covering a family of BBH
configurations (mass ratio, positions, momenta, spins).

| Stage | Scope | Branch |
|-------|-------|--------|
| **A1** | Paper reproduction (single configuration, 4 test cases) | [`a1-reproduction`](../../tree/a1-reproduction) |
| **A2** | Parametric PINN — single parameter (mass ratio $q \in [1,10]$) | see below |
| **A2 variants** | baseline / operator / champion / champion2 | [`A2-base`](../../tree/A2-base) · [`A2-operator`](../../tree/A2-operator) · [`A2-champion`](../../tree/A2-champion) · [`A2-champion2`](../../tree/A2-champion2) |
| **A3** | Multi-parametric PINN — 8 parameters (masses/positions/momenta/spins) | [`a3-multi-param`](../../tree/a3-multi-param) |

Each variant branch is self-contained: its own README (method + results),
the code flattened at the repository root, and only the reference-solution
tools it needs. `main` hosts the shared core.

## Method in one page

The Hamiltonian constraint (Lichnerowicz equation) with the puncture
singularity split:

$$\Delta\psi + \frac{1}{8}K_{ij}K^{ij}\,\psi^{-7} = 0, \qquad
\psi = \frac{1}{\alpha}\left(1 + \sum_{k=1}^{2}\frac{m_k}{2|\mathbf{x}-\mathbf{x}_k|}\right) + u,$$

where the unknown field $u$ is regular at the punctures.

- **Guide ansatz**: $u = \kappa\, u_g\,(1 + \phi_\theta)$, where $u_g$ is the
  analytic Lousto–Zlochower approximation and $\kappa$ minimizes the
  Hamiltonian energy; the network only learns $\phi_\theta$, so
  boundary/asymptotic conditions are satisfied exactly.
- **Loss**: PDE residual (volume, Sobol QMC) + Robin exterior boundary +
  singularity regularization, balanced by exponential moving averages.

See each branch README for what changes relative to this core.
