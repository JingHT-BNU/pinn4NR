# A2-rar —— 残差主动采样变体(A2-3,负结果,已闭环)

本分支与 `A2-champion` 同树:rar 不是独立脚本,而是
`a2q_train.py --variant rar` 的训练配方变体。本文件仅标记该方案分支。

## 设计

残差主动采样(Residual-Active Refinement):每 250 步采 4096 候选点,
按 |PDE 残差| 排序取前 1024 入池;内点批 = 固定集随机采样 + 池点。
动机:把算力集中在残差大的区域。

## 结果(q∈[1,10],18 配置,81³ vs L48)

train mean **3.20e-2**(champion 平台 ~3.2e-2 持平;断点续跑至 10000 步)→
负结果。

## 证明的结论

主动采样不突破平台——残差大的区域是远场,但那里的误差是引导解形状的
系统性偏差(第③层),加密采样无法修复,只有改变 ansatz 结构
(opv3 加性自由场 / opv6 远场乘性)才能解决。

方案矩阵与三层结构诊断见 `A2-opv6` 分支 README 与
`D:\AIs\PINN\reports\A2_v6_最终成品报告_20260902.md`。
