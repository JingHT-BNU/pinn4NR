# A2 —— 单参数 q 参数化 PINN

目标：训练**一个**网络，使其在质量比 `q = m2/m1 ∈ [1, 10]` 上任意取值时，
都能达到 A1 单配置 solve 的精度水平。

物理设定：`m1 = 0.5`，`m2 = 0.5q`，孔位 `x± = (±3, 0, 0)`，动量 `P± = (0, ±0.2, 0)`，无自旋。
训练集 45 个配置，其中 5 个（q15 / q25 / q50 / q74 / q86）为零样本 held-out。

**当前状态：opv6 / v6a 已通过全部门槛（2026-09-02）。
2026-09-12 起在其上做物理信息增强（PDE 残差项 + 独立远场监督），见第 5 节。**

### 为什么需要新评估口径

旧官方口径（81³ 网格 / [-30,30]³ / rcut=0.3）格距 0.75，**对峰区几乎失明**。
新口径：窗口 [-10,10]³、N=161（快速档 81）、rcut=0.1，并显式区分
global / peak(r<1.5) / ring(r<0.5) / valley / far(r0>5) 分区指标。

A1 base 在新口径下的校准值 **T = 9.4954e-3**（峰高比 h=1.007，谷深比 d=0.989），
A2 门槛以它为基准标定。


## 3. 版本谱系

| 版本 | ansatz 形式 | 结局 |
|---|---|---|
| `baseline` | 基线 ansatz | 参照基准 |
| `c2`（champion2） | `u = κu_g(1 + w·ψ)` 乘性 MLP | 峰区好；远场无自由度 |
| `operator` / `opv2` | branch–trunk 加性算子 | 体积改善，峰区回退 |
| `opv3` | 加性 Δ_θ + 奇点窗 χ | **体积突破**；峰区回退（h 0.74–0.86） |
| `opv4` | `u = κu_g(1+w·ψ_N) + Δ_F·χ_far` 混合 | 峰区全过，唯卡 global |
| `opv5` | 无窗加性 | 淘汰（h 0.80–0.91） |
| **`opv6`** | opv4 **+ 远场乘性通道 `m_F`** | **Final 方案，45/45 全过** |

### opv6 的关键设计（改代码前必读）

- **`m_F`**：低频截断编码 [0.5,1,2] + `tanh` 有界 + 末层零初始化，
  由 `χ_far = σ((ρ−0.8)/0.25)` 门控，**近峰机械关断**，专职修正远场。
  它修补的是结构性缺陷：κ\*_spec 是全局单一尺度，并不等于远场最优 κ。
- **频率截断编码** `_freq_embed([1,2,4,8,16])`：替代旧指数频率（最高约 1096，
  曾是 opv3 高频抖动的来源）。
- **双线性鞍点教训**：`branch·trunk` 的末层**不能同时零初始化**（梯度恒为零），
  只零初始化 branch；近场/远场 MLP 是普通链，末层零初始化即可。
- 参数编码 `[log10 q, m2/5]`；`m2 = 0.5q` 实际冗余，可作微优化剪掉。

### 六轮迭代的杠杆有效性排序

1. **`m_F` 远场乘性通道 = 突破点**：far 误差一击降 5–7 倍（2.44e-2 → 3.4e-3）。
2. **refsub_v3 远场加权**：global −20%（q10 首次过 G1），但收益递减。
3. **光滑化正则**（远场 Laplacian + 轴向凸性 hinge）：signflip 23–26 → 9.6–15。
4. **容量排除**：v4b 参数量 ×2.5，global 纹丝不动 → **容量/步数不是杠杆**。
5. 粗糙度量化（二阶导符号翻转计数）是"凸起/凹陷"的有效诊断。
6. 兜底降噪后处理（diffusion / Fourier）**未启用**（`m_F` 消除误差源后无必要）。

### 已排除的负结果

- **θ 噪声增强**（见 `versions/noise/SCHEME.md`）：3.23e-2 平台，无收益。
- **RAR 主动采样**（见 `versions/rar/SCHEME.md`）：3.20e-2 平台，无收益。
- lr 直接 5e-4 微调会**打碎**已收敛的解（L_ref 4e-5 → 1.06）；微调应用约 4e-5。

- **45/45 配置（含 5 个零样本）全部通过 G1 / G2 / G3。**

### 5.4 关键结论

1. **Hamilton 残差项（`--pde-w`）有效且安全**。它惩罚的是真实残差
   $R=\Delta u+S$，而既有 `--smooth-w` 惩罚的 $|\Delta u|^2$ 把解往调和方向
   偏置、并未使用物理信息。权重标定：`--pde-w` 与 $L_{\rm ref}$ 同样做 EMA
   归一，故 `~1` 表示同等权重；$10^{-3}\sim10^{-2}$ 时几乎无效果。
   **微调学习率必须 ~1e-5**，4e-5 会打碎已收敛解。
2. **远场残差的根因是 `L_ref` 只覆盖 $r\le10$**：`x_int` 的 $r_0$ 上界恰为
   10.000，`x_bnd` 落在 $r_0{=}10$ 球面。而谱参考解用径向紧化
   $r=R_0(1+s)/(1-s)$ + 球谐 $l\le48$ 表示，可在任意半径求值 ——
   故远场参考解可以低成本生成（`post_refs_v4.py`）。
3. **远场值监督必须做成独立损失项**。若并入 `refsub`，要让远场在
   $\Sigma w\,u_{\rm ref}^2$ 里占到份额就得把 $w$ 抬到 ~26，于是 $\Sigma w$
   被远场占掉 88%，内区（尤其峰尖 ring 区）被挤掉：实测 v6f 的 45/45 配置
   global L2RE 全部变差、ring 区 1.40×。独立成项后 $L_{\rm ref}$ 可保持不动，
   v6g 的 global L2RE 回到 v6a 水平而远场收益全部保留。
4. **远场残差不跟踪值误差**（`diagnostics/far_value_error.py`）：v6f 把远场
   值误差降了 3.9×（2.68e-2 → 6.88e-3），远场残差却纹丝不动。因
   $R=\Delta e+R_{\rm ref}$，残差取决于误差的**曲率**而非幅值。
   v6g 进一步佐证：其值误差（8.07e-3）与 v6f（6.88e-3）几乎相同，但残差
   好 1.9×。**两个量由不同手段控制**：

   | 目标 | 有效手段 |
   |---|---|
   | 远场**值**精度 | 远场参考解监督（`--far-w`） |
   | 远场**残差**（光滑度） | PDE 残差项（`--pde-w`）+ 训练步数 |
5. **q=1 的反演对称缺陷**：$q=1$ 时构型在 $x\to-x$ 下自映射，偶极应严格为 0。
   实测 $|d|$：谱参考解 2.315e-8、v6a 4.535e-2、v6g 8.917e-3、**v6i 2.868e-3**。
   而 $q\ne1$ 时模型与参考解能对上 3~4 位有效数字（v6g：$q=5$ 时 2.983 vs 2.983），
   说明是**纯对称性**缺陷。已加 `--sym-w` 软约束。
   **注意采样区**：偶极是在 $r\in[10,26]$ 的球面拟合上提取的，而 refsub 的点
   几乎都在 $r<10$ —— v6i 的 $l_{\rm sym}$ 降了 17 倍而拟合偶极只降 3.1 倍，
   即为该不匹配所致。故需 `--sym-far` 让约束改在远场点采样。
6. **单一网络的容量是硬约束**：以上物理项都在与 in-box $L_2$RE 争夺拟合能力。
   v6i 训练中 $L_{\rm ref}$ 由 7.1e-7 升到 8.4e-7，说明内区拟合是**真的**
   被拉走了（不是泛化问题）。若要同时占优，需改变 ansatz 的容量分配方式，
   而非继续调权重。
7. **代价的机理不是"门控泄漏"**（已实测否定）：`near` / `branch` / `trunk` /
   `mfar` 是四个**互不共享参数**的子网，`_embed_x` / `_embed_p` 只是无参数的
   sin/cos 编码。`diagnostics/far_gate_leak.py` 实测远场通道在 $\rho<0.8$
   只贡献 **0.84%**（q10/v6g），故收紧 `near_cut` 无效。
   真正的代价发生在**参数更新层面**（共享 Adam + 全局 `clip_grad_norm_(10)`），
   见 v6k 对照实验。
