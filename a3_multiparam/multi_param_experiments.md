- 根因级修复是窗函数：W 必须**逐点确定**（只依赖该点 ug），与采样统计/配置/批次无关；

- 教训：**冒烟测试参数（--N-Omega 1000）会掩盖窗函数 bug**——少量采样点采不到近奇点，

### 可视化修复两轮（原 viz_peak_fix 摘要 + 2026-08-30 第三轮）

## 二、谱方法参考解套件

### 方法

- 求解哈密顿约束 Δu + (1/8)(ψ_s+u)⁻⁷K̄K̄ = 0（与 PINN/引导解同一方程、同一 ψ_s
  分解），u(∞)=0，无建模近似。球谐谱方法：两奇点中点球坐标；径向紧化
  r=R0(1+s)/(1−s) + Chebyshev 配点；角向 Gauss-Legendre × 均匀网格，l≤L；
  每 l 稠密 LU + 迭代精化×2；非线性用源项延拓 + Anderson 加速。

### 验证（base vs TwoPunctures 外部真值锚定）

| 分辨率 | L2RE(vs TwoPunctures) | 耗时 |
|---|---|---|
| N_r=256, L=16 | 4.2e-3 | ~1.5 min |
| N_r=384, L=32（旧套件） | 8.8e-4 | ~2 min |
| **N_r=512, L=48（当前套件）** | **6.35e-5**（全半径均匀） | ~10-15 min/配置 |

谱收敛正常（16→32 提升 4.8×，32→48 提升 14×）；比 v4 PINN 的 1.65e-2 精确 ~260 倍。
float32 求值 vs float64 相对差 4.4e-7（安全）。

### 用法

```bash
# 单个算例(默认即 L=48)；参数顺序 m+, m-, x+, x-, P+y, P-y, S+z, S-z
.venv\Scripts\python.exe -u paper\tools\spectral_reference.py --params "0.5,0.5,3,-3,0.2,-0.2,0,0" --out paper\tools\refs\ref_base.npz
# 与现有参考解对比(验证模式)；算子自检；批量生成 6 个代表配置
.venv\Scripts\python.exe -u paper\tools\spectral_reference.py --params "..." --compare paper\tools\reference_u.npz
.venv\Scripts\python.exe -u paper\tools\spectral_reference.py --selftest
.venv\Scripts\python.exe -u paper\tools\make_refs_batch.py [--force]
# 针尖精度复核(分辨率自收敛 + FD 残差认证)
.venv\Scripts\python.exe -u paper\tools\verify_ref_tip.py --labels train_0059,train_0164
```

- npz 键：`x_ref`、`u_ref`（与旧格式兼容）、**`radial_coeffs`**（K×(N_r+1)
  complex128，7-20 MB）、`raw`、`xc`、`meta`。输出网格 `--grid-n 197`（±30，奇数
  保证 z=0 面恰在网格上）。
- `SpectralPunctureSolver.from_coefficients(path)` 免重解对任意点集求值
  （`evaluate(pts, chunk, dtype)`，float32 快速档）。
- L=48→L=64 未测；针尖峰在 L=48 未必完全收敛（见 §三），TwoPunctures 锚定与
  FD 认证支持其作为当前真值。

开发中修过的求解器 bug（备查）：cheb 差分矩阵符号反；球谐递推漏 P_1^0 与负 m 补全；
构造器把 θ 当 μ=cosθ；float32 链 (2m−1)!! 溢出；迭代精化把不动点残差地板从 ~1e-5
压到 4.7e-11。

## 三、针尖复核：参考解真值确认（2026-08-29）

**动机**：viz 显示模型针尖比参考解高 2-3×，需排除"参考解针尖欠分辨"。

方法（`verify_ref_tip.py`）：① L32 vs L48 分辨率自收敛（稠密轴 6953 点）；
② 与谱离散无关的 FD 局部 PDE 残差认证（2 阶中心差分 Δu vs (1/8)ψ⁻⁷K̄K̄，
盒子 x 以奇点为中心、y/z 以 0 为心）。

| 检查 | 0059 x+ 针尖峰 | 0164 x+ 针尖峰 | x-（重质量）针尖峰 |
|---|---|---|---|
| L32 | 0.3948 | 0.0226 | 0.0186 / 0.0040 |
| L48 | **0.4952** | **0.0305** | 0.0184 / 0.0042（收敛） |
| 结论 | **L32 欠收敛 −20%** | **L32 欠收敛 −26%** | L32 已收敛 |

FD 局部残差（相对盒内源峰）：0059 L48 中位数 8.7e-4、p95 1.0e-2；最大值 ~1×源峰
仅在最内 r≲0.03-0.05 层（FD 自身失效区，非解误差）。

**判定**：
- 用户怀疑部分成立：旧 L=32 参考在轻质量+自旋针尖确实欠收敛，6 个参考解已全部按
  L=48 重新生成；
- **模型针尖过冲是真实的**（修正真值后 +2.1×/+2.6×）；且 L=48 还揭示了反方向问题：
  0154/0234/0256 针尖引导解**低估**真值 10~15%，模型被锚定跟着低估——修正因子
  上下限两个方向都不够 → v5 放开 c_max=1.0；
- 无镜像对称假象（镜像偏差 0.81 属正常物理不对称）；r≲0.05 最内层参考解自身误差
  O(10%)，L=64 未测。

复核脚本 bug 教训（已修复）：①逐奇点针尖掩膜必须按 |x−xp|<0.5 限定，min 距离掩膜
会让两区给出相同最大值；②FD 盒子 y/z 必须以 0 为心，否则盒子离奇点 ~6 单位、
源项量级差 7 个数量级、检查完全失效。

## 四、v5 结果与诊断（2026-08-30）

### 4.1 训练与评估

- 50000 步 / 7.4h（服务器），c=0.2→**0.654**（未顶死 1.0，幅值上限不再卡脖子）；
  L_ref均 1.5e-3→**2.8e-5**（step ~34000 起跳变）；L_sup均 ~8e-3；L2tip均 ~1e-3
  量级震荡；w_ref 课程衰减 167→84。
- **base L2RE = 5.23e-3**（v4 1.65e-2 → 3.2× 改善）。分区：r<0.5: 1.47e-2 /
  [0.5,2]: 1.07e-2 / [2,10]: 4.5e-3 / **r>10: 3.57e-2**（远场系统性 +5e-5 偏移，
  见 §五-7）。
- PDE 残差 train 1.06e-6 / 零样本 val 8.2e-6；Robin 3.6e-6。

### 4.3 结论：三个根因 + κ 排查

1. **不是 κ 错误**。同一配置两个奇点的引导偏差**方向相反**（0059：轻奇点高 1.47×、
   重奇点低 1.49×；0164：高 1.90× / ≈持平）——全局尺度 κ 不可能造成反向偏差。
   这是 LZ 引导解的**形状误差**（对轻质量+高自旋近场高估、重质量低估）；
   base 的 bulk 引导-参考 relRMS≈3% 亦为形状误差量级。
2. **W=tanh(ug/0.05) 的固定绝对尺度 0.05 压制重质量配置**：其针尖 ug~1e-3~5e-3 →
   W≈0.02~0.32 → 修正上限 1+c·W=1.01~1.21，而需要 ×1.18~1.27——**数学上不可能**，
   模型恰好骑在上限上（实测 model/guide=1.007/1.016/1.210 = 上限值）。v4 的全局
   归一化 bug 与 v5 的固定 0.05 是同一问题的两种形态：**W 的尺度必须逐配置自适应**。
3. **tanh(h) 是"配置级常数"而非逐针尖特征**：同一配置两奇点处 tanh(h) 几乎同值
   （+0.226/+0.226 等），而两奇点需要的修正方向相反（0059：×0.68 / ×1.49）——
   网络学出折中值，两边都不对。加上轻质量奇点针尖极窄（u>0.1 区域体积 ~5e-4，
   每步 1.5M 监督点中期望仅 ~5 个落在其上），监督信号被稀释，0059 轻针尖始终没被纠正。
4. 0164/0256 的 tanh(h) 饱和 ±1：c=0.654 + W 上限仍紧张，且同一 h 难以同时满足
   两个奇点的不同需求（0164 轻奇点因此过冲到 0.42×，真值要 0.53×）。

### 4.4 train_0256 尖峰右侧"断点"

**绘图采样伪影，非解/非引导解问题**（2026-08-30 已修复）：引导/模型曲线曾用
Δx≈0.019 粗采样（参考解 Δx≈0.0012），尖峰本征宽度 ~0.05，粗折线在峰侧形成台阶状
假"断点"；dx=1e-4 稠密扫描证明 guide 处处光滑无 NaN。修复后三条曲线统一稠密采样。

## 五、已知问题与后备方案

1. **W 逐配置自适应尺度**（§4.3-2 的对症修复，v5.1 首选）：u_scale 从常数 0.05 改为
   随配置缩放（如 u_scale(θ) ∝ 该配置引导解峰值/最大值），使各配置针尖 W≈1。
2. **逐点幅值 c(x)**（原 v5 后备）：c=c_max·σ(head(x))，空间变化的幅值上限。
3. **监督点对超窄尖峰加密**：针尖监督点在轻质量奇点 r<0.3 子壳内定额分配，
   而不是在整个 [0.02,2.5] 球壳里按体积稀释。
4. **修正头逐针尖化**：更高坐标编码频率或更宽网络，让 h 能在 ~0.05 尺度上逐奇点
   取值（当前 FiLM 的参数通路强、空间通路在近场分辨率不足）。
5. **soft-L∞ 空间大残差加权**（原设计文档 §6.1，v5.1 候选）：只加在已分离的针尖
   损失项内，β~1 起调，EMA 归一化照旧。
6. **加性修正头**（v6 候选）：u = κ·(u_g + W·g_θ)，针尖相对修正 >50% 时乘性 ansatz
   天然吃力。
7. **远场系统性偏移**：base r>10 L2RE=3.6%、赤道差值图全平面 +5e-5 偏移——
   u_g 远场形状偏差（A2 已知）+ 可能的 κ ~2% QMC 噪声；可在远场加 1/r 形状
   修正项或提高 κ 积分点数。
8. 若改 ansatz/W：训练配置指纹会变，旧检查点自动备份后从头训练（机制见 README）。

## 六、设计文档评估结论（原《设计文档评估_剩余误差参考价值》摘要）

对根目录《参数化PINN求解器设计方案》《参数维度加权逻辑详解》逐项对照当前代码：

- **已实现/被超越**：FiLM、线性参数归一化、方案一（相对残差归一化）= per-config EMA
  （v5 又细分为体/针两套）、方案三（按源强度归一化）被 EMA 覆盖。
- **值得跟进**：① soft-L∞ 空间大残差加权（§五-5，唯一漏掉的旧权重层，与针尖聚焦
  采样互补）；② L2RE 自适应 α——谱求解器（~10 min/配置）使其首次可测：给 5-8 个
  覆盖高自旋/轻质量角落的**验证**配置生成参考解，定期测分区 L2RE、按 L2RE^γ 偏置
  采样；③ 按难度偏置配置访问频率（与 EMA 不冲突）。
- **缓做/另排**：θ 噪声退火（对针尖无梯度贡献，且会平滑掉合法的陡峭 θ 依赖，
  若做只做方式 A、δ≤0.02、中后期）；尺度不变性约化（物理正确但大重构，v6）；
  敏感度加权（暂无必要）。
- **强烈建议**：留出法验证——从 100 个 val 配置挑 5-8 个生成 L=48 参考解，报告
  逐配置分区 L2RE + 逐参数针尖峰值扫描曲线（此前零样本只能看 PDE 残差）。
- 最新状态与优先级排序见根目录 `todo.md`。
